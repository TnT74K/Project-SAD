# راهنمای  تهیه مستندات پروژه درس تحلیل و طراحی سیستم

## مقدمه

هدف از تهیه مستندات پروژه، ارائه یک گزارش فنی، منظم و استاندارد از مراحل تحلیل و طراحی سیستم است. این گزارش باید نشان دهد که گروه، تمامی مفاهیم تدریس‌شده در کلاس را به‌صورت صحیح در پروژه پیاده‌سازی کرده است. کیفیت نگارش، ساختار گزارش و رعایت اصول مستندسازی، همانند محتوای علمی در نمره نهایی تأثیرگذار خواهد بود.
