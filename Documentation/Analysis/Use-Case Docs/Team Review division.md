# Checklist:
چک لیست کنترل کیفیت activity diagram و use-case diagram
1. از منطق و قواعد activity diagram و use-case diagram به درستی استفاده شده است
2. نمودار رسم شده به درستی فرآیند را براساس تحلیل نیازها و منطق سیستم نشان میدهد
3. نمودار راهنمایی های مناسبی برای مرحله پیاده‌سازی میدهد 
4. هنگام پیاده سازی از روی نمودار به ابهام بزرگی بر نمیخوریم
5. اگر پیاده سازی این بخش براساس این نمودار انجام شود، مشکلی پیش نمی‌آید
6. هر activity diagram فقط و فقط معادل یک use-case از use-case diagram مربوطه باشد

نکته: اگر در activity diagram یه یوزکیس مثل A مجبور شدین یوزکیس B که قبلا هم نمودار داشته رو بیارین، ذکر نام کافیه
