#  ریویو درباره Problem & Root-cause analysis پروژه  
ریویو درباره Problem & Root-cause analysis پروژه:  
  
سلام محمد حسین  
من خروجی کار رو قشنگ بررسی کردم و بعدش با AI چک لیست ساختم تا یبار دیگه دقیقتر بررسیش کردم و این مواردی هست که در عمق متن پیدا کردم:  
  
1.  این مورد هم درنظر بگیر که کاربران برای پیداکردن کسب‌وکار خدماتی موردنظرشون توی شهرهای بزرگ دچار مشکل میشن و معمولا نمیتونن خدماتی با سابقه خوب رو پیدا کنن. مخصوصا وقتی که عجله داشته باشن و توی شهر غریب باشن. (این دومین مشکل بزرگیه که سیستم ما هدف داره حل کنه) پس اگه توی همه مراحل (از تحلیل اولیه تا جمع‌بندی) مشکل، این هم درنظر بگیری خیلی عالی میشه. پیشنهاد میکنم یه نگاه به Project Charter توی شاخه Doc/Charter بندازی.  
  
2.  یک سری موارد هستن که در محدوده پروژه ما جا نمیشن. مثل پرداخت آنلاین و موارد مربوط بهش. این موارد رو با خط قرمز مشخص کردم  
<div dir="rtl">3.  صفحه دوم مورد ۴، جمله آخر رو متوجه نشدم</div>  
<div dir="rtl">4.  یک سری جملات پیشنهادی نوشتم که به نظرم به متن اضاف بشن میتونه بهتر بشه</div>  
<div dir="rtl">5.  این مورد هم اضافه کن که این مشاغل معمولا باید هزینه های زیادی برای راه‌اندازی چنین سیستم‌هایی رو بدن. ولی چون ثبتنام کسب‌و کار در سیستم ما رایگانه، میتونه این مشکل رو تا حد خوبی حل کنه</div>  
<div dir="rtl">6.  توی بخش «Fishbone» و نمودارش، توی زیر بخش Technology مسئله هزینه های زیاد راه‌اندازی چنین سیستمی را هم اضافه کن. و سخت بودن جست و جوی کسب و کار برای مشتری هم بنویسی دقت میره بالا.</div>  
<div dir="rtl">7.  اگه فرمت فایل با تم گروه مون هماهنگ بشه بهتره. اینجوری برای نوشتن داکیومنت اصلی، کارمون راحت میشه. پس اگه میشه یه فایل ورد بساز با تم نمونه‌ای که توی پوشه گذاشتم.</div>  
<div dir="rtl">8. راستی AI پیشنهاد داد برای مشکل دومی ( پیداکردن کسب و کار مناسب در شهر بزرگ) یک ‌۵-چرای مجزا بسازیم</div>  
  
درکل متن کامل و خوبی بود ولی با این موارد بالا، میتونه پروژه رو بهتر پوشش بده. بازبینی رو روی یه فایل کپی از اصلیه توی همون شاخه آپلود کردم.
