در ادامه فهرستی از **دستورات ابتدایی و پایهٔ گیت** در **ترمینال مک (macOS Terminal)** را می‌بینی؛ همراه با **نام کامل دستور، مثال، و توضیح کوتاه**.  
همهٔ این دستورات در لینوکس و ویندوز هم یکسان هستند.

---

## 1. تنظیم هویت (فقط بار اول)
### دستور:  
`git config`

### مثال:
```
git config --global user.name "Your Name"
git config --global user.email "your@email.com"
```

### توضیح:  
برای معرفی نام و ایمیل به گیت. این اطلاعات داخل کامیت‌ها ذخیره می‌شود.

---

## 2. ایجاد مخزن گیت
### دستور:  
`git init`

### مثال:
```
git init
```

### توضیح:  
در پوشه فعلی یک مخزن گیت جدید می‌سازد و یک پوشه `.git` اضافه می‌کند.

---

## 3. کلون گرفتن (دانلود پروژه از GitHub یا هر ریپوی دیگر)
### دستور:  
`git clone`

### مثال:
```
git clone https://github.com/user/repo.git
```

### توضیح:  
نسخه کامل پروژه را روی سیستم شما دانلود می‌کند.

---

## 4. وضعیت پروژه
### دستور:  
`git status`

### مثال:
```
git status
```

### توضیح:  
نشان می‌دهد چه فایل‌هایی جدید یا تغییرکرده‌اند، و وضعیت staging چطور است.

---

## 5. اضافه کردن فایل‌ها به Stage
### دستور:  
`git add`

### مثال‌ها:
```
git add file.txt
git add .
```

### توضیح:  
فایل‌ها را برای کامیت آماده می‌کند.  
`git add .`
 یعنی همه تغییرات.

---

## 6. ثبت تغییرات (Commit)
### دستور:  
`git commit`

### مثال:
```
git commit -m "Add new feature"
```

### توضیح:  
تغییرات Stage را در تاریخچه پروژه ثبت می‌کند.

---

## 7. مشاهده تاریخچه کامیت‌ها
### دستور:  
`git log`

### مثال:
```
git log
```

### توضیح:  
فهرست کامیت‌ها را با زمان، نویسنده و پیام نشان می‌دهد.  
برای نسخه کوتاه‌تر:

```
git log --oneline
```

---

## 8. ایجاد شاخه جدید (Branch)
### دستور:  
`git branch`

### مثال:
```
git branch feature/login
```

### توضیح:  
یک شاخه جدید می‌سازد، بدون اینکه وارد آن شود.

---

## 9. تغییر شاخه (Switch/Checkout)
### دستور:  
`git checkout` یا `git switch`

### مثال:
```
git switch feature/login
```

### توضیح:  
به شاخه‌های دیگر جا‌به‌جا می‌شود.

---

## 10. ادغام شاخه‌ها (Merge)
### دستور:  
`git merge`

### مثال:
```
git merge feature/login
```

### توضیح:  
تغییرات شاخه‌ای دیگر را با شاخه فعلی ادغام می‌کند.

---

## 11. گرفتن تغییرات جدید از سرور (Pull)
### دستور:  
`git pull`

### مثال:
```
git pull origin main
```

### توضیح:  
آخرین تغییرات از ریموت را دریافت و ادغام می‌کند.

---

## 12. ارسال تغییرات به سرور (Push)
### دستور:  
`git push`

### مثال:
```
git push origin main
```

### توضیح:  
کامیت‌های شما را به مخزن ریموت (مثل GitHub) می‌فرستد.

---

## 13. اضافه کردن ریموت جدید
### دستور:  
`git remote add`

### مثال:
```
git remote add origin https://github.com/user/repo.git
```

### توضیح:  
یک اتصال جدید به مخزن آنلاین اضافه می‌کند.

---

## 14. مشاهده ریموت‌ها
### دستور:  
`git remote -v`

### مثال:
```
git remote -v
```

### توضیح:  
آدرس‌های ریموت متصل به پروژه را نشان می‌دهد.

---

## 15. مقایسه تغییرات
### دستور:  
`git diff`

### مثال:
```
git diff
```

### توضیح:  
اختلاف‌های قبل و بعد از تغییرات را نشان می‌دهد.
